# Changelog

All notable changes to this repository are documented here.

This project follows [Semantic Versioning](https://semver.org/). For this static website, a release version represents the published site snapshot rather than an installed application.

## [0.1.2] - 2026-08-22

### Added
- Added a GitHub Actions check that validates HTML parsing and verifies local asset references on pushes and pull requests targeting `main`.

## [0.1.1] - 2026-08-20

### Changed
- Added a clear repository and deployment overview to the project documentation.
- Documented safe manual updates, rollback, and the GitHub Pages deployment model.

## [0.1.0]

### Added
- Initial personal portfolio website baseline.
